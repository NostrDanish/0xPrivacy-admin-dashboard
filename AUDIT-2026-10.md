# Security Audit — NostrDanish/0xPrivacy-admin-dashboard — 2026-10-20

## Summary
Medium pass on the admin surface. This is a Nostr-native admin SPA: /admin and /inbox routes are UI-gated client-side (useIsAdmin → pubkey === OWNER_PUBKEY or owner-signed on-chain admin list), and all config mutations are NIP-78 events that must be signed by an authorized key — so there is no server-side session or password to bypass. No hardcoded credentials: the only embedded key material is the owner's hex PUBLIC key (c450…d3c). No committed secrets found. Findings: 0 Critical / 0 High / 2 Medium / 2 Low.
